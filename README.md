# Jazzine — Personal CV Website

A responsive personal CV and portfolio website built with HTML, CSS, and JavaScript. It showcases a professional introduction, skills, projects, experience, education, and contact links.

## Technologies Used

- HTML5
- CSS3 (responsive layout, transitions, and animations)
- Vanilla JavaScript
- Google Fonts (DM Sans and Space Grotesk)

## Student

Jazzine

## Features

- Responsive desktop, tablet, and mobile layout
- Mobile navigation menu
- Smooth section navigation
- Scroll progress indicator
- Scroll-reveal animations
- Project showcase cards
- Email, GitHub, and LinkedIn links
- Reduced-motion preference support

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
3. Replace placeholders and verify every link before publishing.

## Personalize Before Submission

- Confirm your full name and professional title.
- Add a professional photo if desired.
- Confirm school, degree, year level, and expected graduation year.
- Keep only skills you can confidently demonstrate.
- Verify experience dates, employer details, and responsibilities.
- Replace `your.email@example.com` and social URLs in `script.js`.
- Replace example project repository links in `index.html` with your actual repository URLs.
- Add verified achievements and certifications; do not list credentials you have not earned.

## GitHub Repository

Create your own repository (for example, `personal-cv`) and push these files. Use meaningful commits as you build and test the site, rather than one final commit only.

Suggested commit sequence while developing:
1. `Create initial CV website structure`
2. `Add responsive layout and visual styling`
3. `Add project and experience sections`
4. `Implement mobile navigation and animations`
5. `Update personal details and verify links`

Only use commit messages for changes you actually make.

## Deploy to Vercel

1. Push the project to your personal GitHub repository.
2. Sign in at [Vercel](https://vercel.com/).
3. Choose **Add New → Project** and import your CV repository.
4. For this static HTML project, no build command is required; the root directory should contain `index.html`.
5. Deploy, then open the generated public URL.
6. Test navigation, project links, email link, image assets, and mobile layout.
7. Submit both your live Vercel URL and GitHub repository URL to your LMS.
